# MnBi2Te4-linear-response
This repository contains the density functional theory (DFT) and Wannier90 input files for the MnBi2Te4 thin films considered in the paper "Linear response of the Chern insulator MnBi2Te4: A Wannier function approach". We also provide numerical data and code to reproduce the layer-resolved static susceptibility of 11-SL MnBi2Te4 (Fig. 4). 

DOI: https://doi.org/10.1103/8xc4-977z

arXiv: https://arxiv.org/abs/2603.11268

## Overview

This repository provides the computational materials needed to reproduce Fig. 4 of the paper, which presents the layer-resolved decomposition of the static reactive susceptibility of an 11-SL MnBi2Te4 system.
